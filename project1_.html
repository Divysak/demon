About HTML: The Foundation of This Website

  • Developer: Created by Tim Berners-Lee in 1991 while working at CERN (European Organization for Nuclear Research) as a way to share documents over the internet.
  • What is HTML? HyperText Markup Language – the standard markup language used to create and structure web pages. It uses tags (e.g., <h1>, <p>, <img>, <table>) to define elements like headings, paragraphs, images, links, and forms.
  • Key Features: Semantic structure for better accessibility; supports multimedia in HTML5 (videos, audio, canvas); works with CSS for styling and JavaScript for interactivity.
  • Evolution: From HTML 1.0 to HTML5 (current standard since 2014), adding features like responsive design, offline capabilities, and APIs for modern web apps.
  • Importance: Powers over 90% of websites worldwide; easy to learn for beginners; maintained by the W3C (World Wide Web Consortium) for open standards.
  • In This Site: This entire webpage is built using HTML for its structure, including sections, navigation, profile, and table – demonstrating basic to intermediate HTML skills in Front End Development.
